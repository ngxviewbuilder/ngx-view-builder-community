# ngx-view-builder Community

Welcome to the **[ngx-view-builder](https://ngxviewbuilder.io)** community repository!

This is the central place for the community to connect, share ideas, and help improve the project. Here you can:

- 💬 **Discussions** — questions, ideas, sharing experiences, and general conversation about the project.
- 🐛 **Bug reports** — found a bug? Report it here so we can fix it.
- 💡 **Feature requests** — have an idea to improve the project? Share it with us!

## How to contribute

### 🐛 Found a bug?
1. Before creating a new Issue, check whether a similar issue has already been reported.
2. Open a new **Issue** and clearly describe:
   - what you were trying to do,
   - what you expected to happen,
   - what actually happened,
   - steps to reproduce the issue (if possible).

### 💡 Have a suggestion?
1. Open a new **Issue** with the `enhancement` or `feature request` label.
2. Briefly describe the functionality you'd like to see and why it would be useful.

### 💬 Want to discuss something?
Use the repository's **Discussions** tab for questions, ideas, or general conversation that isn't a specific bug or feature request.

## Code of Conduct

Let's be respectful to one another — constructive feedback and a friendly atmosphere help the community grow. 🙂
